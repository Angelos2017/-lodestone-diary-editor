しお✦あんエディタ v3.9 正式版

GitHub Pages 更新用のファイル一式です。

更新方法：
1. GitHubのリポジトリを開きます。
2. ルートの index.html をこのZIP内の index.html で置き換えます。
3. favicon.png と apple-touch-icon.png は以前と同じ画像です。すでにGitHubにある場合、再アップロード不要です。
4. 公開後、ページを再読み込みして v3.9 の表示を確認してください。

更新内容：
・入れ子になったカラータグ、文字サイズ、太字などのプレビュー対応
・文字選択がなくても文字色タグを挿入し、タグの内側から入力可能
・その他の装飾ボタンも未選択時に空タグを挿入可能

注意：公開サイトの下書きはブラウザ内に保存されます。念のため更新前に本文をコピーして保管してください。
