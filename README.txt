設置方法
ZIPを解凍し、index.html、favicon.png、apple-touch-icon.png を同じ場所に配置してください。
既存の日記内容とテーマ設定はブラウザのlocalStorageに保存されます。公開前にバックアップと動作確認を推奨します。
